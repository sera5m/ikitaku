# Teaching iki real-world concepts

Method: **priori first (what can exist), then examples (this thing, this c).**
The thought tree is the same R7→R0 ladder. Attributes are how examples attach
without renaming the platonic.

This is not English class. Words are aliases. Iki stores **verbs + families +
attribute bags + xp cases**.

---

## 1. The tree (what to fill)

```
R7  task / "is this even the right bag"     (place_report: world is a superset)
R6  strategy                                hunt / scientific / Kant / origin
R5  PURPOSE (platonic possibility)          22 object verbs + a few R6
R4  family / axis                           one-loop vs two-loop; map-math vs table
R3  species / named form                    partition-then-order; walk-circle
R2  micro schema                            cmp-swap, trap-add, energy-loss tick
R1  region / bag                            this series, this program, this xp
R0  surface                                 numbers, opcodes, names-as-bytes
```

Teaching **adds a node**, it does not skip ranks. A real-world “cat” is not a
new R5. It is `info` (a bag exists) + `bound` (body) + `absorb/emit` (eat/heat)
+ `repeat` (alive on the time axis) + attributes `{living, path, energy-loss}`.

`f(x) → f'(x)+c`: F is the possibility; c is the example’s extra attributes.

---

## 2. Priori = possible worlds, not facts

Lock these **before** examples. They are synthetic a priori (open to challenge):

| priori | R5 | what it licenses |
|--------|-----|------------------|
| a bag can exist | info | objects, names, numbers |
| a bag can be copied | copy | memory, offspring-as-copy (not identity) |
| one→one keep shape | map | physical law, table, synonym |
| many→one | reduce | mass, sum, “how many” |
| along an axis | repeat | time, walk, loop, heart |
| compare then path | decision | choice, branch, not a table |
| defer on time | wait | delay, sleep, season |
| undo a known wrap | invert | phase, thaw, unsort if you still have the perm |
| in / out of session | absorb / emit | sensor, print, food, speech |
| constraint | bound | body, law, container |
| find a witness | seek | template, “that part of the bag” |
| rearrange by key | order | sort, rank, left-to-right |

Until these exist as catalog rows, no amount of photos of cats will attach.
That is incomplete priori — `place_report` already flags it.

---

## 3. Examples = attribute bags under a family

An example is not a new verb. It is:

```
parent R5 | R4 family | attributes[] | conf interval | xp reward
```

Use `teach_context(fact, lo, hi)` then `xp_record`. Metaphor scores **some**
attributes (Jaccard), never the whole costume.

Worked pattern (already tested):

| example | R5 | R4 | shared attrs | not shared |
|---------|----|----|--------------|------------|
| walk in a circle | repeat | one-loop | closed, path, energy-loss | two-lobe |
| figure-8 | repeat | two-loop | closed, path, energy-loss | center |
| accumulator | repeat | accum-loop | repeat, energy-loss | path, closed |

Same F, different R4, partial F overlap. That is how real kinds split.

---

## 4. Curriculum (base possibilities → specific)

**Layer A — licenses (priori, few cases)**  
info, copy, map, reduce, repeat, decision, wait, invert, bound, emit, absorb,
order, seek, split, join, compare, sequence.

**Layer B — axes (R4)**  
iterator vs time; map-math vs map-table; one-loop vs two-loop; path vs accum;
template as seek-family.

**Layer C — world kinds (still not new R5)**  

| kind | assemble from | first examples |
|------|----------------|----------------|
| object | info + bound | stone, cup, array |
| motion | repeat + path | walk, orbit, current |
| living | repeat + absorb + emit + energy-loss | plant, animal (not “soul”) |
| tool | sequence + bound + emit | hammer, program |
| person-name | info + name | the 30-name list |
| weather | map-math on time axis | temp series |
| event | sequence + cause | A→B infrequent |
| mechanism | info+order+repeat acting on itself | iki, vulcan, a clock |

**Layer D — this instance (c)**  
“this cat, this afternoon, this residual.” Teach with conf interval. If
residual stays high, `critique_challenge` → hidden d → ask or extract.

Do **not** start at D. That is the finite-c failure: vague desire without
experience.

## 5. How to actually insert a lesson

1. **Is the R5 locked?** If no → `r5_propose` (unlocked) or add a cat line.
2. **Is the R4 family named?** If no → `r4_propose(parent, family, form)`.
3. **Attribute bag** for the example (≤8 attrs). Metaphor against nearest known.
4. `teach_context` with `[lo, hi]`. Analytic defs stay closed; synthetic stay open.
5. `xp_record` so the next partial-want is not “insufficient priori.”
6. Hunt if two readings compete (goal vs avoid). Invert the farther miss from 50.
7. If the box is opaque, extract; don’t average.

Bounds: chain length 24, integrate depth uint8 0..8, affinity vocab 64,
Hebbian observe cap 64. Recursion stops when depth hits 0 or the chain is full.

## 6. What not to teach as a new platonic

- English words (“cat”, “qsort”, “love”)
- Whole costumes (glass = floor ceramic + clear)
- The unused rest of reality (world_is_superset)
- A self. Iki is a mechanism of data that acts on data.

Those attach as **c**, aliases, or stay outside the session.

**Concept vs definition.** A concept is a list of platonic types + rules below +
properties of those rules (L4 vars). A definition is structure *up* and
recursive. “Atom” as concept = quanta + attract/merge + L4 mass/polarity/
reactivity. That is not the textbook definition.

**Ship of Theseus.** Same F (`info`). Two bottoms: blueprint =
function+shape+relation; atoms = exact bag with full f^n(x)+c. Battery:
metaphor j=0, same R5, different R4. They are not the same species. Iki can
hold both; it should not average them.

**Can bottoms differ under one F?** Yes. Two chains `info→blueprint` and
`info→atom` share slot 0 and bind different f'.

**Atoms in concept space.** Not R5. Not R0. R4 family under `info`:
"base unit of physical matter." Physical matter = structured data that is
**bound**. Fields/radiation are incomplete priori (map-math on space without
a unit — do not invent a verb yet). Molecule is an antiderivative of atom
(bind/merge), still `info|atom`, not a new platonic.

The first 15 attrs are **flat** (`ikitaku_atom.cat`). Gas/liquid/solid are
subjects under the same family: volume-freedom thresholds vs temperature
(energy + entropy + unknown d). Mass = energy-to-move. Binding is
codeterminant with mass, charge, excitability.

**How to teach a fact.** A fact is a subject-row, not a sentence:
`ikitaku_subject_teach(name, r5, r4, attr, val, conf)`.
Iki maps `subject.attr = value` onto the tree. English is the alias.

Pareidolia: wrap fit + high residual + oscillate/irregular → refuse
("wrap on entropy"). Clean structure keeps the wrap.

## 7. Test to run after a lesson

- `r5_lookup` / `r4_under` see the node
- metaphor jaccard to a sibling, not 100 and not 0
- `place_report` incomplete_priori drops after xp
- `integrate(depth)` grows the chain by exactly `depth` (bounded)
- challenge: new residual ≥ 25 opens the presupposition
